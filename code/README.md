# Companion R code

Executable R code extracted from the book sources by `scripts/extract_code.R`.
This file and every script here are generated — do not edit by hand.

Run each chapter's script from the project root (chapters read `data/`
with relative paths). Or run everything in order with `source("run_all.R")`.

Chunks marked `[not executed in the book render]` are commented out: they are
optional examples around heavy or optional packages (PKNCA / nlmixr2 fits).
