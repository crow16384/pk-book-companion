# Data Dictionary

Synthetic example datasets for the book. All generated by `make_example_data.R`
with a fixed random seed — re-running it reproduces the CSVs exactly.
These are **illustrative teaching data**, not real study data.

Units (book-wide convention): time = hours, dose = mg, concentration = mg/L,
weight = kg, clearance = L/h.

## pk_iv_bolus.csv

Single-subject IV bolus profile (subject 101) used in Chapters 10, 19, 20 for
manual NCA and `PKNCA` workflows.

| Column | Type | Description |
|--------|------|-------------|
| `USUBJID` | character | Subject identifier (ADaM-style; here only "101") |
| `TIME` | numeric | Actual sampling time after dose (h); 0 = dose time |
| `CONC` | numeric | Observed drug concentration (mg/L) |
| `DOSE` | numeric | Administered dose (mg), IV bolus |
| `ROUTE` | character | Dose route; constant `"IV"` in this file |

Generation model: true profile `C(t) = (100/20)·exp(−0.15·t)` with lognormal
observation noise (SD 0.08 on the log scale) added to all time points, floor
0.01 mg/L, rounded to 3 decimals. 10 rows (one subject).

## pk_oral_multi.csv

Twelve-subject oral-dose profile used in Chapters 12, 26, 28 and exercises.

| Column | Type | Description |
|--------|------|-------------|
| `USUBJID` | character | Subject identifier ("001"…"012") |
| `TIME` | numeric | Actual sampling time after dose (h) |
| `CONC` | numeric | Observed drug concentration (mg/L) |
| `DOSE` | numeric | Administered dose (mg), oral |
| `WT` | numeric | Body weight (kg) — allometry covariate |
| `SEX` | character | `"M"` / `"F"` — categorical covariate example |

Generation model: one-compartment oral (Bateman) with between-subject
variability — `ka ~ lognormal(1.2, σ=0.25)`, `k ~ lognormal(0.18, σ=0.2)`,
`V ~ lognormal(25, σ=0.15)` L, `F = 0.7`, dose 100 mg; lognormal residual noise
(SD 0.1); weights `~ N(70, 8)` kg, sex coin-flip; 11 time points per subject,
132 rows.
